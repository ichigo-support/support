# チャットレディ配信サポートサイト

**カテゴリ**: いちごチャット（チャットレディ）

在籍キャストが配信を始める・続ける・トラブル対応するための操作手順とテンプレ文をまとめたサポートサイト。GitHub Pagesで公開中: https://ichigo-support.github.io/support/

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | 配信の始め方（PC起動 → OBSBOTの美化設定 → コピペ操作 → ラブンス起動） |
| `routine.html` | 配信前後の流れと稼ぐコツ（配信前チェック、待機の姿勢、配信後のお礼、定期対応） |
| `tweet.html` | つぶやき（サムネイル用の一言）の文例集。アダルト／人妻／おっぱい／コスプレ・イメプレ／エンジェル・ピア／パーティー中／ノンアダルト／在宅の8カテゴリ |
| `reply.html` | 秘密メッセージの定型文（挨拶・お礼・簡易返信・その他） |
| `mail.html` | お気に入り登録・お礼・途中退室・リクエスト対応などへの返信メール文例 |
| `tech.html` | 接客の会話テクニック（入室直後の声かけ、脱衣の引き延ばし方、アダルトプレイ中の会話例など） |
| `faq.html` | 配信中の対応・誘い文句の断り方・身だしなみ・稼ぐコツ・稼働実績のQ&A |
| `trouble.html` | 遠隔おもちゃ不調・画面フリーズ・ネット切断・PC再起動などのトラブル対応手順 |
| `other.html` | Wi-Fi情報・ルーム利用ルール・キャンセル規定・仮眠/忘れ物の取り扱い |

Bootstrap Icons（CDN）＋自前の`css/style.css`・`js/main.js`のみ、ビルドツールなし。

## 現状

- ナビゲーションから使われている9ページのみで構成（`routine.html`の「配信中」セクションと内容が重複していた未使用ファイル`standby.html`は削除済み）
- GitHubリポジトリ名は`support`のまま。GitHub Pagesで公開中

## 注意（要対応の可能性）

`other.html`の「wifiについて」に、事務所Wi-FiのSSIDとパスワードが**平文でそのまま**書かれている。このサイトはGitHub Pagesで公開中のため、現時点でこの情報がインターネット上から閲覧できる状態になっている。
